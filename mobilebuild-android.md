# Android Build Guide — The Fridge & Cupboard

Complete step-by-step to build the Android app and submit to Google Play.

---

## Prerequisites

- **Android Studio** Ladybug (2024.2.1) or newer — https://developer.android.com/studio
- **JDK 17** — bundled with Android Studio, or install via SDK Manager
- **Node 20+** and **Bun** (or npm)
- **Google Play Console** account ($25 one-time fee)

---

## One-time setup (first build only)

```bash
# 1. Pull the repo and install dependencies
bun install

# 2. Build the web bundle
bun run build

# 3. The /android folder is already in the repo (generated by Capacitor).
#    If you ever need to recreate it:
#    npx cap add android

# 4. Sync web assets + plugins into the Android project
npx cap sync

# 5. Generate all icon & splash sizes from resources/
npx capacitor-assets generate \
  --iconBackgroundColor '#0b0b0f' \
  --splashBackgroundColor '#0b0b0f'
```

---

## Open in Android Studio

```bash
npx cap open android
```

This launches Android Studio with the project at `android/`.

---

## Build the signed AAB (Android App Bundle)

1. In Android Studio, go to **Build → Generate Signed App Bundle / APK...**
2. Select **Android App Bundle (.aab)** — required for Play Store.
3. Create or select your **upload keystore**:
   - Key store path: `~/.android/keystore-thefridgeandcupboard.jks`
   - Key alias: `thefridgeandcupboard`
   - Validity: 25+ years (Google requires 25+ years for app signing)
   - **Back this file up.** If you lose it, you cannot update the app ever again.
4. Choose **release** build variant.
5. Click **Create** → Studio outputs `android/app/release/app-release.aab`.

---

## Configure Google Play

1. Go to https://play.google.com/console
2. Create app → **The Fridge & Cupboard**
3. Application ID: `com.thefridgeandcupboard.app`
4. Set up **Play App Signing** (Google manages the final signing key).
5. Upload your first `.aab` to **Internal Testing**.

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.CAMERA" />

<uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
<uses-permission android:name="android.permission.READ_MEDIA_VIDEO" />
```

## After every web update (no resubmission needed)

Because the app loads `https://thefridgeandcupboard.com` at runtime, most web changes appear instantly in the installed app.

You only need to rebuild and resubmit when:
- App icon, splash screen, or name changes
- New native plugin or permission added
- Capacitor version bumped

## Troubleshooting

| Issue | Fix |
|---|---|
| `SDK location not found` | In Android Studio: File → Settings → Appearance & Behavior → System Settings → Android SDK → copy Android SDK location → set `ANDROID_SDK_ROOT` env var |
| Gradle sync fails | File → Sync Project with Gradle Files |
| Build fails with JDK error | File → Settings → Build, Execution, Deployment → Build Tools → Gradle → set Gradle JDK to JDK 17 |
| Icons not updating | Delete `android/app/src/main/res/mipmap-*` and re-run `npx capacitor-assets generate` |
